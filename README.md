# Carrinho Automoto por cor

Projeto acadêmico de desenvolvimento de um carrinho automatizado, com o objetivo de aplicar conceitos de programação, lógica computacional, eletrônica e automação.

O projeto busca desenvolver um sistema capaz de controlar a movimentação do carrinho de forma automática, utilizando componentes eletrônicos e programação para executar comandos e realizar tarefas.

## Objetivos
- Aplicar conceitos de automação e eletrônica.
- Implementar controles de movimentação.
- Integrar hardware e software.
- Trabalhar com desenvolvimento colaborativo.

## Tecnologias
- C
  
## Componentes
2 – Motores DC de 6V com rodas;

1 - Roda Boba Rodízio Giratório;

1 – Placa Arduino UNO R3 com cabo USB; 

1 – Motor Ponte H L298n para Arduino; 
2 – Sensores Infravermelho;

1 - Sensor RGB TCS230;

1 - Sensor Ultrassônico - HC-SR04

1 – Mini Protoboard 170 Pontos;

2 – Clip de Bateria 11V, conector de bateria para arduino e Shield; 

2 – Baterias 3,7V Alcalina recarregáveis;Jumpers Macho-Macho, Fêmea-Fêmea e Macho-Fêmea.
